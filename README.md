### 🚀 Projetos de Maior Impacto

Aqui estão os principais projetos que desenvolvi para consolidar meus estudos:

#### 🎬 Cinema IA
Plataforma web focada na automação de conveniência residencial e entretenimento doméstico. O sistema une o controle de streaming de vídeo ao gerenciamento de pedidos de bomboniere diretamente da poltrona, utilizando IA para recomendações de lanches baseadas no gênero do filme.
*   **Tech Stack:** JavaScript, Node.js, HTML5, CSS3, APIs REST.

#### 📝 To-Do List Inteligente
Gerenciador de tarefas automatizado que otimiza a rotina diária do usuário de forma ativa. A aplicação realiza requisições assíncronas para a API da OpenAI para que, a partir do título de uma tarefa, sejam geradas subtarefas organizadas e dicas de produtividade.
*   **Tech Stack:** JavaScript, Node.js, API OpenAI (GPT).

#### 🔲 Sistema de Cadastro com QR Code (SENAI)
Software desktop desenvolvido para automatizar o processo de registro e controle de acesso institucional de pessoas. A aplicação cadastra o usuário, gera um QR Code exclusivo para identificação digital rápida e faz a persistência segura dos dados.
*   **Tech Stack:** Python, SQL, Bibliotecas de Imagem.
